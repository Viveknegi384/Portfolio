# Resume Folder

## Instructions

1. Place your resume PDF file in this folder
2. Rename it to `resume.pdf` (or update the path in the code)
3. The "Download Resume" button on your portfolio will automatically link to this file

## Current Setup

- **File location**: `public/resume/resume.pdf`
- **Code reference**: See `src/app/components/Hero.tsx` (line ~137)
- **URL path**: `/resume/resume.pdf`

## Updating the Resume

Simply replace the `resume.pdf` file in this folder with your updated version.
